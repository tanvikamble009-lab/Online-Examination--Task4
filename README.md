# Online Examination System (Java)

## Project Overview ##
The Online Examination System is a simple Java console-based application that allows a candidate to:

Login using username and password
Update profile credentials
Start an online exam
Answer multiple-choice questions
Submit automatically when time is over
View final score
This project is developed using Core Java concepts and is suitable for beginners and internship-level Java projects.



## Features ##
User Login Authentication
Profile Update Option
Multiple Choice Questions (MCQs)
Timer-Based Exam
Auto Submission

Console-Based Interface

## How to Run the Project 
Step 1: Open Terminal
Open Command Prompt or PowerShell in the project folder.

Step 2: Compile the Java Files
javac Main.java Candidate.java Questions.java

Step 3: Run the Program
java Main
